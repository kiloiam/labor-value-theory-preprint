二、为什么 B 档要你本人操作

OSF Preprints / SocArXiv / PhilArchive / Preprints.org 都不要求机构身份，但都需要一个属于你的账号并勾选「本人有权发布」的作者声明。我不代注册账号、不代勾选权属声明、不代填投稿表单；同时，现有 OSF 账号的显示名与作者署名不一致，直接用它创建 preprint 会显示另一个名字，因此也不代创建。

我能做的是把门全部打开：每个平台的逐字段预填内容、摘要、投稿说明、许可选择与 PDF 路径都已备好，见 投递包 与 open-archive-kit.zip。你只需复制粘贴、上传 paper.pdf、点击提交。

推荐顺序：① OSF Preprints（免费、给 DOI、被 Google Scholar / OpenAlex 索引）→ ② SocArXiv（社会科学对口）→ ③ PhilArchive → ④ Preprints.org。每投一处，站内 存档链接表可自行补充。

三、自动收割链路（不需要人工提交）

Zenodo DOI → DataCite 登记 → OpenAIRE 收割（实测已收录）→ OpenAlex / Semantic Scholar / BASE / CORE / Google Scholar 依次收割。这些聚合器不接受单篇投稿，只收割登记源，因此存在数天到数周的延迟。本轮实测：DataCite 200、OpenAIRE total=1、OpenAlex 404、Semantic Scholar 404、Crossref 404（Zenodo DOI 由 DataCite 管理，不在 Crossref）。详见 AGGREGATORS-R5.json。

Google / Bing 的 sitemap ping 端点本轮实测为 404 / 410，已停用；有效通道是 IndexNow（4 个端点）与站点地图，二者本轮均已重新提交。

四、C 档为何不代做

viXra 已解锁：其官方 Submission Notes 要求 real name、禁止 nom de plume；作者已澄清 Didgeridoo 是真实英文姓名而非笔名，因此该要求已满足，本轮把它从「不代做」移入 B 档，并备好逐字段表单与专用投稿版 PDF。作者已于 2026-11-16 本人提交，回执显示已接收、待管理员检查；官方要求两天内等待结果且 Do not resubmit，目前尚无 viXra 编号或公开链接。

其余 C 档与姓名无关：arXiv 需要 endorsement 背书人与机构认证；SSRN / RePEc / HAL / ResearchGate / Academia.edu 需要平台账号与机构邮箱；正式期刊需要同行评审与通讯作者。这些是账号、背书与权属问题，不注册、不伪造背书、不绕过。
