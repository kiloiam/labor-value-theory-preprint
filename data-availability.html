说明

本文为理论分析，不依赖外部数据集，因此没有数据仓库、变量表或复现脚本。为避免「无数据」被误解为「不可核验」，本页列出全部可独立核对的材料。

可核验内容包括：规范 HTML 全文与逐页原稿影印、9 页去标识化 PDF、纯文本全文、单文件离线 HTML、BibTeX / RIS / CSL / CITATION.cff 等引用格式、DataCite / Dublin Core / Highwire / MARCXML / METS 等元数据、以及全站 SHA-256 校验表。

独立存档：Zenodo 概念 DOI 与各版本 DOI、Figshare 干净记录、OSF 项目、GitHub 两个仓库与 Releases、公开 Gist、Software Heritage、Wayback Machine、Telegraph 索引页，以及第七轮新增的多个独立资料托管副本。每一份都指向同一规范链接。

校验方法：下载 `paper.pdf` 后计算 SHA-256，与 `ARCHIVE-MANIFEST-R7.json` 与 `CHECKSUMS.sha256` 比对；全文文本层与 PDF 文档属性（`/Author=Didgeridoo`）也应一致。若某副本与规范版本不符，以规范链接及其校验和为准。
