三、为什么不做这些

Google Indexing API 官方只接受 JobPosting 与 BroadcastEvent；普通论文页调用属于滥用，可能导致配额被撤。Google / Bing 的旧 sitemap ping 端点均已停用（实测 404 / 410）。

学术侧的 OpenAlex、Semantic Scholar、Crossref 不接受单篇人工投稿，只能等待从 DOI 注册表与开放仓储自动收割；CORE 有速率限制，BASE 有反爬页，本轮均如实记录为未确认。
