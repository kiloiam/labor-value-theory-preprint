Statement

This is a theoretical paper with no external dataset: there is no data repository, variable table or replication script. To avoid reading 'no data' as 'not verifiable', this page lists everything that can be independently checked.

Verifiable material includes the canonical HTML full text and facsimile page images, the 9-page de-identified PDF, plain-text full text, a single-file offline HTML copy, citation formats (BibTeX, RIS, CSL JSON, CITATION.cff), metadata (DataCite, Dublin Core, Highwire, MARCXML, METS) and the site-wide SHA-256 manifest.

Independent archives: Zenodo concept and version DOIs, the clean Figshare record, the OSF project, two GitHub repositories and their Releases, a public Gist, Software Heritage, the Wayback Machine, Telegraph index pages, and the independent document-host copies added in round 7. All point back to the same canonical URL.

To verify: download `paper.pdf`, compute its SHA-256 and compare it with `ARCHIVE-MANIFEST-R7.json` and `CHECKSUMS.sha256`. The text layer and PDF document property `/Author=Didgeridoo` should also agree. If a copy disagrees, the canonical URL and its checksums are authoritative.

Frequently asked questions

Is there raw data?
No. A theoretical analysis has no dataset.
How do I confirm a download is the original?
Compare the SHA-256 checksum and PDF document properties, and use the canonical URL.
What if copies disagree?
Treat the canonical site and its checksum manifest as authoritative; anonymous hosts are redundancy only.
