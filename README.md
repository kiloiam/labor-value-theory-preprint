# 劳动价值论是历史性范畴：当代价值危机

**作者**：Didgeridoo　|　**状态**：网络预发布预印本（Preprint），**非期刊正式发表**，未经同行评审　|　**许可**：CC BY 4.0　|　**日期**：2026-11-16

从历史唯物主义立场阐明劳动价值论作为历史性范畴的界限，分析当代自动化生产条件下价值规律面临的结构性危机；提出包含自动化技术资本的价值修正模型、利润向负向政治性维稳成本 P 的转化，以及商品社会自我修复的「四重不可能」。
